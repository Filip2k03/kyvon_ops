# GitHub Discussions plan

Discussions are not enabled or created by this repository change. If enabled by
the maintainer, use these categories:

- Announcements
- Ideas
- Q&A
- Show and tell
- Architecture
- AI agents
- DevOps

Suggested first prompts:

1. Which read-only infrastructure surface should KyvonOPS support next: Docker, systemd, or Kubernetes?
2. What approval evidence should an AI-assisted infrastructure operation show?
3. What would make you trust a local-first DevOps desktop application?
4. Show your current server-management workflow.
5. Which existing terminal tools should KyvonOPS complement rather than replace?

Moderation rule: answers must distinguish implemented behavior from proposals;
no credentials, private hosts, or unsupported security guarantees.
