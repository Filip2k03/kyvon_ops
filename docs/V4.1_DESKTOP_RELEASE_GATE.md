## Signing

CI reads `APPLE_*` and `TAURI_SIGNING_*` from GitHub secrets when present. If they
are empty, Tauri produces **unsigned** packages. Do not claim “Apple signed” or
“Authenticode” without a verified signed file.

## Updater

Disabled until a minisign/Tauri updater key is issued and `createUpdaterArtifacts`
is turned on against a HTTPS endpoint that serves signed metadata.

## Final

**LAUNCH BLOCKED** for a public installer drop until the unchecked artifact
rows have CI (or local) evidence and a non-draft GitHub Release exists.
