## Required evidence before release

1. Push a release tag only after CI secrets for signing are configured.
2. Inspect every generated file as a real executable/package, not a placeholder.
3. Generate one `SHA256SUMS` file from the exact published bytes and verify it
   on a clean machine.
4. Test install, launch, first run, SSH fingerprint confirmation, restart, and
   uninstall on every published platform.
5. Publish only the artifacts that passed those checks, then update the final
   report with the exact release URL and commit.
