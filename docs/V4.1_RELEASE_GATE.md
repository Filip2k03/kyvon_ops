Cloudflare tunnel route, signed artifacts/checksum manifest, packaged desktop
SSH session, hosted authentication, and atomic rollback evidence are
unverified. The verified Pages deployment is a separate HTTPS surface; it does
not prove the requested tunnel route to `127.0.0.1:8080`.
