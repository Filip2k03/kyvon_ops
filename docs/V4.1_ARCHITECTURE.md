# KyvonOPS V4.1 Architecture

KyvonOPS is local-first. Public web pages explain and distribute verified
artifacts; the installed desktop application owns local credentials, sessions,
server profiles, and infrastructure operations.

```text
PUBLIC WEB      DESKTOP (Tauri 2)      MOBILE (when implemented)
     \                |                       /
                  SECURE SESSION
                       |
                 MIND + BRAIN
             voice/UX + context/planning
                       |
                  CONTROL GATE
             policy + capability + approval
                       |
             API / MCP / SSH connectors
                       |
                  KYVONOPS CORE
                       |
                 VPS / Docker / Nginx
                       |
                  AUDIT + DATA
```

The diagram is a design boundary, not a claim that every connector is deployed.
The current repository verifies the public website, Tauri/React shell, SQLite
storage, typed policy/MCP components, SSH transport, telemetry, topology, and
audit primitives. Hosted API, mobile, voice, video, and public Cloudflare
ingress remain unverified or unavailable.

Process, storage, network, and systemd screens consume live telemetry or typed
IPC when the desktop backend is attached. Missing collector data renders
`NoDataState`; they do not invent PIDs, disk percentages, or ports.

## One authorization model

Every privileged path must converge on the same control gate. A request carries
an authenticated actor, target, capability (`READ`, `DIAGNOSE`, `CONTROL`, or
`DESTRUCTIVE`), bounded arguments, risk, and request ID. Mutations require the
appropriate approval, execute through a typed connector, record a redacted audit
event, and return evidence or a safe failure. UI controls are convenience only;
authorization belongs in native/core policy code.

AI and voice may summarize evidence or propose an action. They never receive raw
credentials, expose chain-of-thought, or turn unvalidated output into shell
commands. SSH host keys, session expiry, timeouts, output limits, and changed
fingerprints remain enforced at the connector boundary.

## Product experience

The visual system favors near-black surfaces, restrained cyan/blue accents,
clear hierarchy, readable type, deliberate spacing, reduced motion, and explicit
status labels. The command center should remain calm and legible during a long
incident; animation and decoration must never compete with health, evidence,
approval, or recovery actions.
