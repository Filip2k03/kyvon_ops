## How to produce real installers

```sh
git tag v4.1.0-rc.1
git push origin v4.1.0-rc.1
```

Then open the draft GitHub Release, download assets, verify `SHA256SUMS.txt`,
install on each OS, and only then promote to `v4.1.0`.

Do **not** `curl …/install.sh | sh`. Use `scripts/install.sh --desktop` only after
an AppImage + `SHA256SUMS` exist on the release.
